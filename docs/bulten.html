Sahada Doğrulandı
Redmi Note 8 · 72+ Saat Kesintisiz · Termux:Boot

72+ Saat Kesintisiz: Termux wake-lock ve Termux:Boot kancası ile elektrik kesilip gelse dahi sistem telefon açılır açılmaz kendiliğinden uyanır.

Baresip VoIP Köprüsü: Zadarma SIP santraline TCP üzerinden bağlanır, FIFO named pipe (spk.raw) ile çift yönlü 8kHz ses iletir.

Yerel Bellek ve Mahremiyet: Beden sadece 127.0.0.1 dinler. Tüm konuşma geçmişi ve notlar cihaz içinde kalır; dışa sadece onaylanan LLM çağrısı gider.

01

Bu proje ne işe yarar?

Cebimon, çekmecede atıl bekleyen eski bir Android telefonu (Redmi Note 8 gibi) root atmaya gerek kalmadan, Termux üzerinde çalışan ikinci bir yapay zekâ beynine dönüştürür. Cihaz evinizde şarja ve Wi-Fi'a takılı kalır; hem cebinizdeki günlük telefonunuzdan hem de bilgisayarınızdan Sıfır Terminal Mobil Kokpiti üzerinden kontrol edilir.

Gerçek VoIP Arama

GSM hattı yerine Baresip SIP köprüsü ile Zadarma santraline bağlanır. İstediğiniz numarayı klon sesinizle arar, konuşmayı canlı dinler, barge-in (araya girme) destekler ve transkript çıkarır.

Klon Ses Stüdyosu

Fish Audio entegrasyonu ile Haluk Bilginer, Sedat Peker veya kendi klon sesinizle konuşur. Tarayıcıdan tek tıkla ses ön dinleme yapılabilir.

Sıfır Terminal Kontrolü

Telefonda küçük klavyeyle kod yazmaya son. API anahtarları, klon ses seçimi, hızlı arama ve durum izleme tamamen mobil web panelinden yönetilir.

Kimin İçin Tasarlandı?
  • — Atıl eski telefonunu 7/24 kişisel asistan veya akıllı santral yapmak isteyenler
  • — Kişisel verilerini, konuşmalarını ve notlarını buluta teslim etmek istemeyenler
  • — Kendi santral numarasından klon sesle profesyonel telefon aramaları yürütmek isteyenler
  • — Termux ve Node.js ortamında hafif, sıfır gecikmeli mühendislik arayan geliştiriciler

03

Neler yapamaz? (Güvenlik Sınırları)

✕
Kabuk / Terminal Komutu Çalıştırmaz:

LLM modeline kabuk (shell/exec) aracı kesinlikle verilmez. Ajan sistem düzeyinde yetkisiz bash komutu yürütemez, dosya sistemini bozamaz.

✕
İzinsiz veya Sahte Arama Yapmaz:

VoIP köprüsü yalnızca yapılandırılan Zadarma SIP hesabı üzerinden arar. Ses gidiş hattı testi yeşil değilse arama kapısı kilitlenir (HTTP 423), spam engellenir.

✕
Verileri Üçüncü Taraf Buluta Yedeklemez:

Hafıza tamamen telefonun yerel depolamasında (~/.asistan/) saklanır. Dışarıya yalnızca kullanıcı onaylı API istekleri gider.

✕
Onaysız Bankacılık veya Hassas İşlem Yapmaz:

Geri alınamaz veya kimlik doğrulaması gerektiren işlemlerde ajan yalnızca taslak hazırlar, son kullanıcı onayı olmadan eyleme geçmez.

Kurulum Adım Adım (Saha Doğrulamalı)

  1. F-Droid'den Termux, Termux:API ve Termux:Boot kurun.
  2. Depolama izni verip paketleri güncelleyin: 
    termux-setup-storage
pkg update -y && pkg install -y nodejs-lts git baresip ffmpeg
  3. Wake-lock alın ve arka plan uyutmasını engelleyin: 
    termux-wake-lock
    MIUI Ayarlarında: Termux → Pil Tasarrufu → Kısıtlama Yok ve Otomatik Başlatma → Açık yapın.
  4. Depoyu klonlayıp kurulum betiğini çalıştırın: 
    git clone https://github.com/AppleCurse/asistanim-cebimde-cebimon.git ~/asistanim-cebimde
cd ~/asistanim-cebimde
bash scripts/termux/kur.sh
  5. Servisleri başlatın: 
    bash scripts/termux/baslat.sh
  6. Giriş anahtarını (Token) öğrenip panele girin: 
    cat ~/.asistan/beyin.token
    Tarayıcınızda https://127.0.0.1:20131/ açın ve token'ı yapıştırın.
07

Sıfır Terminal Mobil Kokpit

Telefonda veya bilgisayarda tarayıcınızı açıp https://[telefon-ip]:20131/ adresine girdiğinizde 4 ana sekmeden oluşan dokunmatik kokpit karşılar:

💬 1. Kokpit (Asistan & Arama)

Mikrofon butonuna basarak Türkçe sesli sohbet edebilir, Hızlı Arama Kartı üzerinden istediğiniz numarayı seçip klon sesle tek tıkla arayabilirsiniz.

🎭 2. Sesler (Ses Stüdyosu)

Haluk Bilginer, Sedat Peker, Doğal Emel seslerini tarayıcıdan 🔊 Dinle butonu ile test edebilir, tek dokunuşla varsayılan yapabilir veya yeni özel klon ID ekleyebilirsiniz.

⚙️ 3. Ayarlar & API Merkezi

LLM API anahtarlarını, Fish Audio anahtarını ve Zadarma SIP kullanıcı adı/şifresini formdan yapıştırıp kaydedin. .env ve Baresip otomatik güncellenir.

📊 4. Durum & Geçmiş

Beden donanım durumu, santral bağlantısı, pil seviyesi, bellek notları ve geçmiş VoIP arama transkriptlerini anlık izleyin.

Canlı Ses ve Çağrı Örneği

Sorun Giderme Rehberi

Belirti / Hata Sebebi Çözüm Adımı
HTTP 423 / Ses Testi Uyarısı Güvenlik kapısı: Ses gidiş hattı henüz test edilmediği için arama kilitli. Termux'ta bash scripts/termux/ses-testi.sh çalıştırın. Test tamamlanınca kilit açılır.
Tarayıcı "Güvenli Değil" Uyarısı HTTPS kendinden imzalı yerel TLS sertifikası kullanılıyor. Gelişmiş → 127.0.0.1 sitesine ilerle (güvenli değil) seçeneğine bir kez dokunun.
Giriş Ekranında Token Hatası Token querystring/localStorage üzerinden okunmaz, elle yapıştırılmalıdır. cat ~/.asistan/beyin.token komutundaki 48 karakterlik değeri girin.
Baresip Kayıt Başarısız SIP kullanıcı adı veya şifresi eksik/hatalı. Mobil kokpitte Ayarlar sekmesine girip Zadarma bilgilerinizi kaydedin.
Kamera Siyah Geliyor Termux:API izinleri Android tarafından kısıtlanmış. Android Ayarlar → Uygulamalar → Termux:API → İzinler → Kamera'ya izin verin.
Servisler Bir Süre Sonra Duruyor Android/MIUI pil optimizasyonu Termux'u uyutuyor. Termux'ta termux-wake-lock çalıştırın, MIUI pil tasarrufunu kapatın.
11

Güvenlik & İzin Kapıları

1. Donanım İzolasyonu (Localhost Yalnızca): Beden servisi (beden/server.mjs) yalnızca 127.0.0.1:20130 dinler. Dış ağdan, Wi-Fi'dan veya tünellerden doğrudan beden portuna erişim imkansızdır.

2. Kriptografik Token Doğrulaması: Beyin üzerindeki /saglik hariç tüm API uçları yetkilendirme başlığı (Authorization: Bearer [token]) veya oturum çerezi gerektirir. Token güvenli olmayan querystring parametrelerinden okunmaz.

3. Sıkı Ajan İzin Kapısı: Ajanın LLM fonksiyon çağrılarına (tools) tehlikeli komutlar (arama, SMS) için açık kullanıcı izni şartı konmuştur; kabuk aracı tamamen devre dışıdır.

4. Çift Çaldırma ve Ses Hattı Koruması: SIP köprüsü eşzamanlı çift arama girişimlerini engeller. Ayrıca ses gidiş hattı tanılanmadan arama kesinlikle başlatılmaz.

REST & WebSocket API

Metot / Uç Nokta Kimlik Doğrulama İşlev ve Dönüş Formatı
GET /saglik Gerekmez Sistem ve calismaSuresi durumunu JSON döner.
POST /api/sohbet Token Zorunlu Metin veya sesli girdi alıp LLM asistan yanıtı döner.
POST /api/hizli-ara Token Zorunlu Hedef numarayı seçilen klon ses ile VoIP santralinden arar.
GET /api/sesler Token Zorunlu Haluk Bilginer, Sedat Peker ve aktif sesi listeler.
POST /api/ses/on-dinle Token Zorunlu Seçilen sesin önizleme ses dalgasını base64 döner.
POST /api/ses/varsayilan-yap Token Zorunlu Asistanın kalıcı varsayılan konuşma sesini değiştirir.
GET /api/ayarlar Token Zorunlu Mevcut LLM, Fish Audio ve SIP ayarlarını döner.
POST /api/ayarlar Token Zorunlu LLM, Fish Audio ve SIP ayarlarını .env'e kalıcı kaydeder.
GET /api/hafiza Token Zorunlu Kalıcı kullanıcı notlarını ve bellek maddelerini listeler.
GET /api/gorevler Token Zorunlu Aktif görev tahtasını ve cron hatırlatıcılarını döner.

Sıkça Sorulan Sorular

Telefonuma root atmam gerekiyor mu?
Hayır. Tüm sistem standart F-Droid Termux ve Termux:API izinleriyle root olmadan çalışır. Donanım güvenliği bozulmaz.
GSM SIM kartı takmak zorunlu mu?
Hayır. Arama ve çağrı özellikleri Zadarma VoIP santrali üzerinden Wi-Fi ile gerçekleşir. GSM hattı gerekmez.
Neden Linphone yerine Baresip kullanıldı?
Baresip, Termux bionic derlemesinde çok daha hafif çalışır, netstring kontrol protokolü ile saniyede yüzlerce bayt ses paketini sıfır takılmayla işler.
Bilgisayarımdan veya başka telefondan girebilir miyim?
Evet! Aynı Wi-Fi'da olduğunuz sürece bilgisayarınızın veya şahsi telefonunuzun tarayıcısından https://[telefon-ip]:20131/ adresini açarak bağlanabilirsiniz.
Cihaz sürekli şarjda kalınca pili şişer mi?
Redmi Note 8 akıllı şarj entegresi taşır; ancak uzun ömür için cihazı akıllı priz zamanlayıcısı ile (günde 2 saat şarj) kullanmak tavsiye edilir.
